# Uttam Modi - Full Stack Developer Portfolio

A modern, responsive portfolio website showcasing Java Full Stack and React.js expertise with smooth animations and interactive UI.

## 🌐 Live Demo

**Visit the portfolio:** [https://ucodecrafter.github.io/uttam-resume-app/](https://ucodecrafter.github.io/uttam-resume-app/)

## 📋 Project Overview

This is a professional portfolio website built with React.js to showcase:
- **Full Stack Development** (Java, Spring Boot, React)
- **Technical Skills** across frontend, backend, DevOps, and cloud technologies
- **Professional Experience** with detailed project descriptions
- **Education & Certifications**
- **Interactive UI** with smooth scroll navigation and animations

## ✨ Features

- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile
- **Smooth Scroll Navigation** - Click nav items to smoothly scroll to sections
- **Scroll-to-Top Button** - Quick navigation back to top after scrolling
- **Professional Animations** - Framer Motion animations for engaging UI
- **Typing Animation** - Hero section with React Type Animation
- **Modern Styling** - Gradient backgrounds and CSS3 effects
- **Material-UI Icons** - Professional icon set for social links
- **SEO Optimized** - Proper semantic HTML structure

## 🛠️ Tech Stack

### Frontend
- **React.js** 18.3.1
- **React Router DOM** 6.28.0
- **Framer Motion** - For smooth animations
- **React Type Animation** - Typing effect in hero section
- **Material-UI** 6.1.7 - Components and icons
- **Tailwind CSS** - Utility-first styling

### Styling
- **CSS3** - Custom styling with gradients and animations
- **AOS** (Animate On Scroll) - Scroll-triggered animations

### Tools & Services
- **Axios** - HTTP client for API calls
- **Git & GitHub** - Version control
- **GitHub Pages** - Deployment

## 🚀 Getting Started

### Prerequisites
- Node.js 14+ 
- npm or yarn

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/UCodeCrafter/uttam-resume-app.git
cd uttam-resume-app
```

2. **Install dependencies**
```bash
npm install
```

3. **Start development server**
```bash
npm start
```
The app opens at `http://localhost:3000/uttam-resume-app`

## 📦 Available Scripts

### Development
```bash
npm start
```
Runs the app in development mode with hot reload.

### Build
```bash
npm run build
```
Creates an optimized production build in the `build` folder.

### Deployment
```bash
npm run deploy
```
Builds and deploys to GitHub Pages (gh-pages branch).

## 🐳 Dockerization & ⚡ GitHub Actions CI/CD

### 🐳 Running with Docker Locally

1. **Build Docker Image**
```bash
docker build -t uttam-resume-app .
```

2. **Run Container**
```bash
docker run -d -p 8080:80 --name uttam-portfolio uttam-resume-app
```
Access the application at `http://localhost:8080`

3. **Or Run via Docker Compose**
```bash
docker-compose up -d --build
```
To stop the container: `docker-compose down`

---

### ⚡ GitHub Actions CI/CD Pipeline

The project includes an automated GitHub Actions CI/CD workflow ([`.github/workflows/docker-ci.yml`](file:///.github/workflows/docker-ci.yml)):

- **Automated Testing & Build**: Runs `npm ci` and `npm run build` on every push and pull request.
- **Docker Container Build**: Uses Docker Buildx with layer caching for ultra-fast builds.
- **Publish to GHCR**: Automatically builds and pushes Docker images to GitHub Container Registry (`ghcr.io/ucodecrafter/uttam-resume-app:latest`).
